## Lore 决定与验收边界

“历练节奏偏早”缺口已按 Lore 决定处理：ADV_01 最早第 3 轮、ADV_02 最早第 4 轮，每步 3% 保持不变。4.3 表 ±1 轮只约束推演表里的里程碑，不再将全部通用事件套入该约束。最早轮次保证下限，不保证命中率或截止前结算。

`step` 开头自增 tick，首次入队 flags 记录当步 tick。第 N 轮首步为 (N−1)×30+1；第 60/90 步仍属第 2/3 轮，第 61/91 步才属第 3/4 轮。测试临时将概率设为 1，在真实 step 中验证两事件门槛两侧；另验证第 61 步准行、满 30 步在第 91 步归来。门槛位于角色抽取之前，不消耗 RNG，不登记轮内掷骰；与移除该候选事件的同 seed 世界逐项一致。step/round 两种 cadence 均覆盖，且同一 w.round 的第 60/61 步没有提前占用首次掷骰。

提前跳过抽取和概率会改变与旧版本相比的共享随机序列，因此其他事件的中位数和命中率也会变。本次默认 A/B/C/D 完成率仍为 100/100/98/99%，零操作 D 从旧记录 61% 变为 80%，主殿从 27% 变为 28%。这些是实测结果，不是其他数值调参。

零操作 A/B/C 完成仍为 0；A3/B3/C3 虽分别出现 33/17/4 局，但均未在六轮截止前结算。30 步等待、结算后才计算前置间隔及未结事件占角色的机制均保留。主殿完成 28 局而 SEC_02 只入队 27 局，两者不可混作一个指标。

62 项测试保留原有确定性、资源边界、保存、离线与 v1.1 回归；新增门槛边界、RNG/每轮首次机会、实际离山归来和 schema 校验。旧冷却专项测试仅在测试副本中移除最早轮次，以继续独立覆盖冷却作用域。默认故事与主殿门槛保持通过，不据此宣布全部节奏或整个 M2 验收完成。浏览器验证由指挥官运行。
