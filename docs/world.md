# W1 世界拼装

运行 `npm run world -- --trace`：仅读取 design；重新校准纸色、darken 拼图、裁切北岛桥板并沿桥折线旋转平铺、生成 3200×1400 world.webp 和 320×140 world-mini.webp、追踪可走轮廓、生成建筑掩码报告。旧 base@2x.webp 保留。普通 `npm run world` 也重建轮廓，避免图像与配置漂移。

颜色分类使用草绿/土黄阈值，4px 采样，开闭运算、最大连通域、边界追踪和 Douglas–Peucker 简化。脚本内 reviewed envelope 限制顶面边缘；树干、池塘、溪流、大石及主岛门楼用显式障碍孔扣除。每岛 39–40 个顶点。参考图的色彩不足以自动区分树冠与草坪，人工修订约束因此保留在生成脚本中，可复现。`data/world.json` 仅由渲染层读取。

桥使用原图桥板裁切拼接，无程序绘制的美术。桥宽 40 世界单位，折线允许穿过桥头到岛面；无传送。桥的反复纹理和接岸效果需外部浏览器视觉验收，静态预览已经检查。

预览生成到 `/tmp/xianfu-world-walkable-preview.png`，含轮廓、障碍孔、桥、点名和建造框。任务指定的 `/Volumes/Media/GrokBot/workspace/xianfu-world-walkable-preview.png` 在当前可写根之外，未尝试越权写入；预览不进入 git。

## 移动和比例

10 单位网格 A*，拒绝斜穿角，2 单位间隔的视线检查进行路径平滑，缓存路径；建筑地块下半部和各级建筑 alpha 包围范围的底座带共同阻挡。返回不可达时停留原处，不退回穿云直线。人物初始出场就位，后续转场沿路径移动，进行中的路线先走完。休息人物也可在打坐点停留。

`DISCIPLE_SCALE=1.0`，精灵画布高 96，实际人物高约 93.71 世界单位。名字按原规则以双倍世界单位避让。目标点选择为 hash(id,tick)，不消费 sim RNG；同目标点按黄金角环形错开。

旧 map.ts 没有固定速度，而是所有转场 1200ms。采用旧居舍前沿到主殿前沿 98.812px / 1.2s ×2 得到明确的 `WALK_SPEED=164.6866764`。新路径 197.624 单位，1.2 秒；未达到 8–15 秒，本阶段不调整。阶段 2 建议 13.2–24.7 单位/秒（取 20 则约 9.88 秒），不能把此选择谎报为旧代码已有的固定速度。

默认镜头 (1500,900)，zoom=0.45，可见宽约 1422 单位；全景 zoom=0.2。640×360 渲染视口全景适配 3200×1400 时纵向留纸色边；该状态中心锁定 y=700。缩略图点击定位，显示世界坐标视口框。

## 建筑

具体比例和 alpha 边界见 world-buildings.json；比例是相对当前项目内 `*-map@2x.webp` 的显示倍率。居舍 1.0（现有导出尺寸已受 1.15×地块宽限制），门高「不适用」。主殿门高比 0.6、静修室约 0.429。炼丹房 t1/t2 分别约 0.683908 / 0.610256，无 alpha 像素进入静修室地块，底边均 1055 ≤1090。二分搜索取得当前锚点下的最大可行比例。

药圃采用 Iris 无小屋 624×489 原图，完整导出，不裁顶。`npm run assets` 同时刷新世界放置记录；可用 `GARDEN_SOURCE_DIR` 指定同规格源目录。

两级源图到世界的 scale 均为 0.24（允许区间内最大值），按地面四角外接框中心对齐东岛框中心 (2616,926)。t1 锚点 (2616.36,970.28)，t2 锚点 (2616.24,975.08)；四角记录于 manifest 的 footprintWorld 和 docs/world-buildings.json。t2 上下超框各 4.08，处于 ±6 容差内。两级地面四边形并集与原建筑预留区共同阻挡寻路。tier2 运行时 ADD 同纹理呼吸光 alpha 0.15–0.25、周期 5 秒；缺图时使用已有 fallback。

## W3b 浏览器反馈修复

目的地使用 `hash(id, floor((tick + hash(id) % 12) / 12))`，开局仍采用原主岛分散；空闲按动作选全世界落脚点，建筑做工去建筑前沿，药圃去东岛前沿，采石点取原主岛本地位置换算后的最近可走点。仅使用表现层确定性计算，不调用模拟 rng、不写模拟状态。

原步速 20 时最长锚点路线 2274.789 单位需要 113.739 秒，不能满足 120 秒 stint 的 70% 上限。保留短途步速 20；长途巡航 `max(20, pathLength / 80)`，全行程至多 80 秒，动画步频同步比例调整。居舍→主殿仍为 197.624 单位 / 20 = 9.881 秒。stint 稳定性限于动作类型和工作地点未变时；实际模拟工作切换仍可改变目标。

旧 `overlap` 是导出 map 图中 alpha > 0 的像素方格经放置变换后，与固定 **B_MEDIT 地块矩形**相交的像素个数（不是世界面积、不是 alpha 加权面积）。因此静修室 t1=7237 / t2=7089 是自身占地。现在 `overlapSelfSlot` 表示与自身地块的相交像素数，`overlapNeighborSlots` 表示与其余建筑地块及集会广场 `[1413,920,1631,1046]` 的并集相交像素数；`overlapsBySlot` 给出各邻框明细。静修室两级邻框计数均为 0，比例仍为 1，无需缩小。附带测量发现居舍两级与广场矩形分别有 31/29 个导出像素相交，保留其现有位置并明确记录，不能把静修室零重叠说成全世界零重叠。

药圃 t2：原纹理保留，上层同纹理 ADD，alpha=`0.2+0.05*sin(now*π/2500)`，范围 0.15–0.25，周期 5000ms。叠层沿原纹理 alpha，不额外铺遮花的实色遮罩；参数满足峰值要求。GPU 下是否洗白花色仍由外部截图复验，本轮没有运行浏览器。

门人列表固定九列，状态内再分 32px 图标列与 nowrap 文字列，多事件按钮留在末列；窄屏由列表内部横向滚动。名字避让包含所有弟子的整幅精灵保守包围盒，按镜头 zoom 换算至少 4 CSS px 间距。

外部执行 `node scripts/e2e.mjs http://localhost:4173`：追加独立 debug=1、walkScale=8 页面，多 stint 推进、每 100ms 检查位置，记录 `islandVisits`（到达目标≤12单位的采样数）、`bridgeCrossings`（位于桥折线半宽内的采样数）、`offWalkableSamples` 及总采样次数。前两者是采样命中数，不冒充独立旅程计数。生成多岛全景 `27-world-islands.png` 与跟随行走女弟子的近景 `28-world-female.png`；失败时同样写诊断报告。未执行该脚本，原有外部截图和报告保留。
